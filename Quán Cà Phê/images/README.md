# Image Placeholders

This directory is intended for storing images for the coffee shop website. 

For the website to display correctly, please add the following images:

- `hero-bg.jpg` - A background image for the hero section (suggested: an image of a coffee shop interior or coffee beans)
- `espresso.jpg` - Image of an espresso
- `cappuccino.jpg` - Image of a cappuccino
- `latte.jpg` - Image of a latte
- `green-tea.jpg` - Image of green tea
- `black-tea.jpg` - Image of black tea
- `croissant.jpg` - Image of a croissant
- `chocolate-muffin.jpg` - Image of a chocolate muffin
- `coffee-shop.jpg` - Image of your coffee shop for the About section

You can use your own images or find royalty-free stock photos online. For best results, use images with the following dimensions:
- Menu item images: 400x300 pixels
- Hero background: 1920x600 pixels
- About section image: 600x400 pixels
