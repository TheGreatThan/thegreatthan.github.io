Quán Cà Phê - Coffee Shop Ordering System

Now with Cloud Storage! The ordering system now uses Firebase to store data in the cloud, allowing seamless synchronization across all devices.

Before using the system, please set up your Firebase project by following the instructions in the FIREBASE_SETUP.md file.

Welcome to the Quán Cà Phê Coffee Shop Ordering System. This system consists of two parts:

Customer Ordering System Owner Dashboard

How to Use

For Customers:

  • Browse the menu and add items to your cart
  • View your cart and adjust quantities
  • Fill out your information and place your order
  • Receive an order confirmation with your order number

For Shop Owners:

  • View pending orders in real-time
  • Get notified when new orders come in
  • Mark orders as completed or cancelled
  • View order history
  • Manage menu items (add, edit, or toggle availability)

Note: For the system to work properly, you need to add image files to the images directory. You can also add a notification sound file to the sounds directory.
