# Sound Files

This directory is intended for storing sound files for the coffee shop website.

For the website to function with audio notifications, please add the following sound file:

- `notification.mp3` - A short notification sound that will play when a new order is received on the owner dashboard

You can use your own sound file or find royalty-free sound effects online. For best results, use a short, attention-grabbing sound that is not too jarring or loud.
